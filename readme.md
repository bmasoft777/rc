# Сайт "Компьютерный мастер Михаил"

## Структура папок
Убедитесь, что ваша папка проекта выглядит так:
remont-rybinsk/
├── index.html
├── styles.css
├── script.js
├── privacy.html
├── terms.html
├── README.md
├── img/
│ ├── avatar.webp (Ваше фото, 100x100px, закругленные углы)
│ └── title.webp (Фоновое фото первого экрана, 1920x1080px, затемненное)
├── otzyvy/
│ ├── a1.webp ... a27.webp (Аватарки клиентов, квадратные или круглые, ~100x100px)
└── works/
├── 11.webp, 12.webp, 13.webp (Фото чистки ноутбука)
├── 21.webp, 22.webp, 23.webp (Фото чистки ПК)
└── video.mp4 (Видео ремонта крышки, желательно сжать до 5-10 МБ)
